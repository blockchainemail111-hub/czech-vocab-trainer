# Тренажер чеських слів

Node.js + Express сайт для вивчення чеської лексики.

## Запуск локально

```bash
npm install
npm start
```

Потім відкрий http://localhost:3000

## Публікація на Vercel

1. Створи новий репозиторій на GitHub.
2. Завантаж у нього всі файли цього проєкту.
3. У Vercel вибери Add New → Project → Import Git Repository.
4. Вибери репозиторій і натисни Deploy.

Vercel автоматично визначає Express/Node.js застосунок.
